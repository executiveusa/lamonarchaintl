# La Monarca Launch Readiness Gates

## Product Truth

Before launch:

- No fabricated businesses, interviews, routes, prices, reviews, or availability.
- Every public place requires verification evidence.
- Every public story has an editorial approval path.
- Every walking tour requires real-world testing before sale.

## Editorial Flow

A story moves through:

1. Interview scheduled
2. Interview completed
3. Source material ready
4. Draft created
5. Facts checked
6. Editor approved
7. Published

## Place Flow

A place moves through:

1. Draft
2. Verification queue
3. Human evidence recorded
4. Verified
5. Editorial publish decision
6. Public La Guia entry

## Tour Flow

A tour moves through:

1. Draft concept
2. Verified stops selected
3. Route tested physically
4. Timing and accessibility reviewed
5. Approved
6. Published
7. Monetization enabled

## Technical Gates

- [ ] Supabase migrations reviewed before production apply
- [ ] RLS policies verified in live environment
- [ ] Admin permissions tested
- [ ] Public routes tested
- [ ] No secrets stored in repository
- [ ] Deployment rollback path confirmed

## Business Validation

The first paid experience should be validated with:

- real guide/operator capacity
- real route timing
- real customer interest
- real payment workflow

The catalog is the asset. Tours are monetized experiences built from the catalog.
